# Estudo de Caso: Vinheria Agnello

## Descrição
A Vinheria Agnello é uma empresa familiar especializada na venda de vinhos, conhecida pela qualidade dos produtos e pelo atendimento personalizado. Este projeto mostra o desafio de modernizar o negócio criando uma presença digital para melhorar a experiência do cliente e aumentar a competitividade no mercado.
